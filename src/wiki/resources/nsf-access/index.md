**What:**
NSF ACCESS is a program that allows graduate-level students to fill the role of a PI or principal investigator for entry-level awards with the support of an advisor for a letter of recommendation.

**Steps:**
1. Make an account [here](https://identity.access-ci.org/new-user?_gl=1*1nqgb0r*_ga*MTk0MjEzNTAzMy4xNzc2NzI0MTUw*_ga_CNLGPXPT91*czE3NzcwMTY4NDgkbzIkZzEkdDE3NzcwMTcxNDIkajYwJGwwJGgw)
2. Review available resources
3. Prepare and request an allocation

**Notes:**
* The ACCESS program requires an advisors approval and letter of collaboration, Cristian is happy to fulfill this duty if you reach out to him!
* Read more on the website here: [ACCESS for Graduate Students](https://access-ci.org/get-started/for-graduate-students/)
