Lab Writing Retreat

14th and 15th of October, 2025, from 9:30 am - 4:00 pm

Discussion: Given a community in which one or more species went extinct, why did other species in the community not go extinct? How did land coverage change in this area? What are the environmental factors that led to the extinction or survival of the species?

Schedule Day One:

  1. Intro – Project description, questions, goals
  2. Data collection (species lists, shape files)
  • Group into partners based on dataset
  1. Lunch
  2. Check in: how things are going with data collection, what we might need to change
  3. Run the analysis (create a model that incorporates the data we collected, determine which variables are most important in a given species’ extinction)
  4. Write Methods (if there is time)

Day Two:

  1. Recap of Day One (what we got done, what we still need to do)
  2. Finish Methods
  3. Write Results
  • Team up to write results for different parts of the analysis
  • Figure drafts
  1. Lunch
  2. Check in: how things are going with writing, address any snags
  3. Write Discussion
